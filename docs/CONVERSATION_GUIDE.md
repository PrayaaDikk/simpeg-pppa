# Tech Stack & Rules
- Use Functional Components in React with TypeScript.
- Database columns must always use snake_case (e.g., `user_id`, `is_approved`).

# Localization & UI Language
- The application target audience is Indonesian.
- ALL user-facing text, labels, placeholders, and validation error messages MUST be written in Indonesian.
- Example for button: Use "Kirim Pengajuan" instead of "Submit Application".
- Example for alert: Use "Data berhasil disimpan" instead of "Data saved successfully".
